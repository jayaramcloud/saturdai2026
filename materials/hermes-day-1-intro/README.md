# Hermes Day 1 — Intro to LLMs and Hermes (10 of 10 SVGs)

Ten 1600×900 slide-style SVGs for the talk-only kickoff of the "Agentic AI with Hermes Agent"
course (Fri, Sep 25, 2026). Matches the site's dark purple theme (see `src/app/globals.css`)
using the same categorical palette established in `materials/day-1-intro-to-llms/`: blue
`#5b7cfa`, teal `#0d9488`, amber `#d97706`, magenta `#ec4899`, green `#16a34a`, violet `#8b5cf6`.

Rendered on the site at `/hermes-agent/day-1` via `Slideshow` (`src/components/Slideshow.tsx`),
served from `public/slides/hermes-day-1/`, above the existing lab-notes content on that page.

1. **01-welcome-roadmap.svg** — course title plus a timeline of all 7 sessions with dates and
   titles, "you are here" on Day 1.
2. **02-what-is-an-llm.svg** — condensed AI → ML → Deep Learning → Generative AI → LLM nesting,
   plus a plain-language "what it does / doesn't do" side panel.
3. **03-chatbot-vs-agent.svg** — side-by-side: a chatbot's single question/answer turn vs. an
   agent's perceive → decide → act → observe loop.
4. **04-meet-hermes-agent.svg** — Hermes Agent in the middle, branching to a cloud endpoint and
   a local endpoint, showing it's provider-agnostic by design.
5. **05-hardware-dgx-spark.svg** — DGX Spark spec cards: 128GB memory, 6,144 CUDA cores, 1 PFLOP
   FP4, 200B max params.
6. **06-hardware-mac-mini.svg** — the Mac Mini alongside the DGX Spark, comparing what each
   machine is best suited for during the course.
7. **07-course-pipeline.svg** — Days 2–7 as a left-to-right pipeline, each stage building on the
   last.
8. **08-agentic-example.svg** — one concrete task (check Tokyo time, save a reminder) walked
   through as 4 real agent steps.
9. **09-logistics.svg** — schedule, time zones, cost/access, and sign-up info in four cards.
10. **10-get-ready-day-2.svg** — a 5-item checklist for Day 2 plus a closing call to action.

Open any file directly in a browser to preview, or view in an SVG/vector editor (Figma,
Illustrator, Inkscape) to fine-tune.
