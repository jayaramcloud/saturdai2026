# Hermes Agent Day 8 (bonus) — Build a Chatbot (6 of 6 SVGs)

Six 1600×900 slide-style SVGs for the bonus session on building a safe, public AI chatbot.
Built to match the site's dark purple theme using the same categorical palette as the Day 7
deck (blue `#5b7cfa`, teal `#0d9488`, amber `#d97706`, magenta `#ec4899`, green `#16a34a`,
violet `#8b5cf6`, red/pink `#f5576c`).

Generated by `gen.py` in this folder. Edit the script and re-run it; do not hand-edit the SVGs.
Then copy them to `public/slides/hermes-day-8/` — the source and served copies must stay in
sync (there is no build step that does it): `cp materials/hermes-day-8-chatbot/*.svg public/slides/hermes-day-8/`

Rendered on the site at `/hermes-agent/day-8` via `Slideshow`. The numbers on the slides
(600 characters, 450 tokens, last 6 messages, rate limit 8) come from the real worker at
https://github.com/jayaramcloud/jayaram-app (`src/worker.js`); re-check them there if that code changes.
